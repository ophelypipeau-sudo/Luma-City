# Proposition de poupée de mode cartoon adulte

Statut : concept visuel à valider, aucune modification du jeu.

`concept.png` a été généré avec l’outil intégré imagegen depuis le prompt textuel
`prompt.txt`, sans image de référence d’une marque ou d’un jeu. L’original est
conservé dans le dossier de génération Codex.

La planche propose une base chauve en sous-vêtements opaques à gauche et un look
à droite : cardigan lilas, camisole ivoire, jean évasé et bottines à plateforme.
Direction : traits affirmés, contours nets, ombrages en aplats, attitude mode et
proportions stylisées adultes. Le concept explore la demande de poupée de mode
sans reproduire intentionnellement un personnage précis.

Les deux vues sont des illustrations générées : elles ne prouvent pas un
ajustement des vêtements au pixel près. Le look n’est pas constitué de calques
indépendants, le corps n’est pas découpé et aucun squelette d’animation n’est livré.
Les mains, proportions et repères devront être harmonisés sur une base canonique
après validation, puis les vêtements préparés sur cette base. Un essai d’animation
habillée devra valider les raccords avant de décliner le dressing.

Ni l’ancienne proposition adulte ni cette planche ne remplacent la base active.
Il s’agit d’une proposition artistique, pas d’une validation juridique du jeu.
