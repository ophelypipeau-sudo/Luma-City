# Sols réalistes v1

Création avec imagegen intégré (mode built-in), cinq générations de textures indépendantes. Sources PNG conservées dans `sources/`. Assets WebP 1024 × 1024, qualité 87 : `public/assets/housing/floors-realistic-v1/{wood,herringbone,tile,checker,stone}.webp`.

Chaque famille conserve ses identifiants, achats et couleurs sauvegardées. Le filtre SVG conserve les détails de matière et applique les couleurs du bois ou des minéraux. Les cinq dessins restent regroupés au catalogue. Aucun changement aux personnages, vêtements ou meubles.

Correspondances : parquet standard → wood ; chevrons → herringbone ; carrelage ivoire/rose → tile ; damier → checker ; dalles sable/ardoise → stone. Projection du motif dans le plan du sol et éclairage partagé avec la maison.
