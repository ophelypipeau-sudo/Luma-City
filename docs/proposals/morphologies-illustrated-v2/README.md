La planche comparative a été produite avant cette validation : son pied de page décrit donc le statut de cette étape historique.

La tenue pilote adaptée aux six corps est maintenant dans ../pilot-v6/. Le corps X reste une copie exacte de ../hourglass-v2/hourglass-illustration-v2.png. Le corps 8 retenu est body-8-r2.png ; le premier essai body-8.png est conservé comme source historique.

Aucun étirement global ni assemblage de membres de la planche vectorielle refusée. Les vues gardent les proportions natives 887 × 1774.

Les modèles de morphologies et d'équipements sont conservés. Les contours et coupes de la tenue pilote utilisent les illustrations approuvées, pas les anciennes propositions vectorielles.
