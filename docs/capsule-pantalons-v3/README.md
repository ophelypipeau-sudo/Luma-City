# Capsule pantalons — intégration de face

Les dix dessins validés sont disponibles dans le rayon **Bas** : Dalle, Rocade, Granit, Ruban, Vélin, Ligne, Indigo, Calcaire, Sillon et Fuseau. Les versions retouchées de Rocade et Granit et la création Vélin remplacent leurs propositions de travail uniquement dans cette capsule. Les PNG d’essayage validés et le mannequin canonique sont conservés.

Chaque calque de pantalon garde le repère natif 887 × 1774. Les vêtements et les chaussures sont indépendants. Le manifeste de boutique pointe vers le calque, le masque de matière, la protection des détails et la couverture des jambes. Les deux poses archivées ne sont pas proposées. Le masque de matière teint le tissu en conservant le relief de son dessin. Les pièces métalliques, les surpiqûres contrastées des denims et les bandes crème de Ruban sont exclues de ce masque ; les coutures ton sur ton suivent la teinte en gardant leur relief.
