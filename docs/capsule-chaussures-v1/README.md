# Capsule chaussures — planche de validation

[Planche interactive](planche.html) · [Planche PNG](planche.png)

Dix paires originales : quatre baskets, trois bottines et trois paires de talons. Les vues sont de face sur Iris, avec le pantalon Fuseau comme tenue d’essayage. Les gros plans proviennent des mêmes dessins. Certains essais ont des marges différentes ; la planche les cadre sans modifier les PNG sources ni étirer les proportions.

Les dessins ont été réalisés avec ImageGen à partir de l’[essayage frontal de Fuseau](../capsule-pantalons-v2/sources/10-fuseau.png). La tenue [Prune fumée](../../public/assets/avatar/prune-fumee-v1/source.png) est la référence de finition. Les consignes sont conservées dans [brief.json](brief.json). Pour réexporter la planche sous Windows : `pwsh -File docs/capsule-chaussures-v1/render-planche.ps1`.

Les [tendances été 2026 de Pinterest](https://newsroom.pinterest.com/news/summer-trend-report-2026/) ont inspiré les baskets hybrides et les volumes de running. La [Palette 2026 de Pinterest](https://newsroom.pinterest.com/pdf/pinterest-palette-2026-pdf/) a servi de repère pour le bleu glacier, la semelle gomme et le slingback. Les coupes, empiècements et détails sont originaux ; aucun modèle de marque n’est reproduit.

Après validation : séparer la peau, les chaussures et le pantalon ; recaler chaque paire sur les pieds natifs ; vérifier la silhouette, le sol et les superpositions avec les bas ; séparer les matières recolorables des semelles, lacets et ferrures selon le modèle. Aucun modèle n’est inscrit au catalogue à ce stade.
