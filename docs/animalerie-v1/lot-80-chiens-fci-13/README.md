Création avec l’outil intégré `image_gen`, un appel par illustration. Les prompts complets et les chemins des sources sont conservés dans [prompts.json](prompts.json). Les 80 PNG natifs sont copiés dans [public/assets/companions/](../../../public/assets/companions/), sans déformation ni recoloration par programme. L’Épagneul picard foncé a reçu une correction du fond via le même outil ; sa source initiale et le prompt de correction sont conservés.

Les standards FCI du tableau ont servi à choisir les silhouettes et les palettes. Pour le King Charles, les couleurs ont également été vérifiées dans le [standard du Royal Kennel Club](https://www.royalkennelclub.com/breed-standards/toy/king-charles-spaniel/), le PDF FCI étant indisponible pendant la préparation.

Les races à palette restreinte gardent deux variantes de nuance ou de répartition des marques : les Griffons bruxellois restent roux, les Grands Bouviers suisses tricolores, les Filas de Saint-Miguel bringés et les Bleus de Gascogne mouchetés. Le second Dogue argentin conserve son corps blanc avec une petite marque à l’œil.

Les dimensions et limites des silhouettes sont mesurées sur les pixels d’alpha supérieur ou égal à 16. Ces repères servent au catalogue commun à la boutique, à la collection et aux salons multijoueurs.

Après ce lot : **262 races canines illustrées sur les 364 références FCI du projet**, soit **102 races encore absentes**. Le catalogue complet contient 348 races et 663 pelages. Les anciennes races à un seul pelage restent à compléter séparément.

Validation : les quatre tests de l’animalerie passent, dont le contrôle des 663 PNG RGBA uniques et le parcours adoption/multijoueur. La vérification TypeScript avec `npx tsc --noEmit` réussit également.

Reproduction depuis la racine sous Windows :

```powershell

node scripts/run-tests.mjs tests/companions.test.ts
npx tsc --noEmit
```
